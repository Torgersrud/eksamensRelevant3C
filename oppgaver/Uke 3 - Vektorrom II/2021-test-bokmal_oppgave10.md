La  $A$  være en  $n \times n$ -matrise og la  $A\mathbf{x} = \mathbf{b}$  ha to lineært uavhenige løsninger. Hvilken av de følgende påstandene er riktig?

 rank(A) = 2
 rank(A) ≥ 2, og tilfellet rank(A) > 2 kan forekomme
 rank(A) ≤ n, og tilfellet rank(A) = n kan forekomme
 rank(A) ≤ n - 1 og tilfellet rank(A) = n - 1 kan forekomme
 rank(A) ≤ n - 2 og tilfellet rank(A) = n - 2 kan forekomme
