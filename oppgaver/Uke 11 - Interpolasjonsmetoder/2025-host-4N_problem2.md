## Problem 2 Interpolation (10 points)

The following table shows the values of a function f(x) at the following points:

| $\boldsymbol{x}$ | f(x) |
|------------------|------|
| 0                | 0    |
| 1                | 2    |
| 2                | 6    |
| 3                | 12   |

- a) Compute an interpolating polynomial p(x) of minimal necessary degree for the given data. Simplify the resulting polynomial as much as possible.
- b) Use p(x) to compute an approximate value of f(1.5).
- c) Briefly explain why the interpolating polynomial of minimal necessary degree exists and is unique for this data set.
